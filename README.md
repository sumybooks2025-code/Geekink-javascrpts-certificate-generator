# 🎓 SumyTech School - JavaScript Certificate Generator

A web-based certificate generator built for SumyTech School students.

It allows instructors and students to dynamically generate and download certificates as PNG images.

---

## 🚀 Features

- Enter Student Name
- Enter Course Name
- Select Completion Date
- Live Certificate Preview
- Download Certificate as PNG
- Responsive UI
- Instructor Student List (CSV Included)

---

## 🛠 Technologies Used

- HTML5
- Tailwind CSS (CDN)
- Vanilla JavaScript
- html2canvas (Image Export)
